# Mama's Daily Planner

A responsive daily planner website in English, styled in elegant cream, beige, and brown.

## How to run
1. Download and extract this ZIP file.
2. Open the `mama_daily_planner` folder in Visual Studio Code.
3. Make sure `index.html`, `style.css`, and `script.js` are in the same folder.
4. Right-click `index.html` and choose **Open with Live Server** (install the Live Server extension first), or open `index.html` directly in your browser.
5. Planner data is saved in your browser using localStorage. Use Settings > Export data to create a backup.

## Features
- Home dashboard with daily summaries.
- Monthly calendar with add, edit, and delete event features.
- To-do list with due dates, filters, and checkboxes.
- Notes that can be created, edited, and deleted.
- Grocery list with checkboxes and automatic progress.
- Search across tasks, events, notes, and grocery items.
- 15-minute focus timer.
- Personalized display name and encouraging message.
- JSON data export.

Google Fonts requires an internet connection; the website still works with fallback fonts when offline.
